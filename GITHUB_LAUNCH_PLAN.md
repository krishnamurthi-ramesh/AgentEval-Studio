# GitHub Launch Plan — Earn Adoption, Don't Chase Vanity Stars

GitHub stars are an outcome of usefulness, discoverability, and trust. They cannot be guaranteed or ethically manufactured. Do not buy stars, use engagement pods, or ask unrelated communities for low-value star swaps.

## Before public launch

- [ ] Confirm project name and repository name availability; do a basic trademark/name check.
- [ ] Choose a license after reviewing dependencies and intended contribution model.
- [ ] Ship a working quickstart that succeeds on a clean environment.
- [ ] Include a small public sample dataset with provenance and license.
- [ ] Provide a one-command local demo where practical.
- [ ] Include a short GIF/video showing the user workflow.
- [ ] Publish architecture and evaluator semantics.
- [ ] Add unit tests, integration tests, and CI.
- [ ] Add CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, and issue/PR templates.
- [ ] Document limitations, data handling, privacy, and API key usage.
- [ ] Pin dependencies and publish reproducible release tags.

## Distribution

1. Publish a technical walkthrough explaining the problem and a real reproducible benchmark.
2. Share with relevant practitioner communities only where promotion is allowed; contribute useful answers first.
3. Submit to relevant open-source directories/newsletters when the project meets their criteria.
4. Ask for issue reports and use-case feedback, not just stars.
5. Respond quickly to issues and merge meaningful contributions.
6. Publish changelogs and roadmap decisions transparently.

## Success metrics beyond stars

- Successful clean installs / quickstart completions.
- Unique users returning to run another experiment.
- Issues with reproducible bug reports.
- External contributors and accepted pull requests.
- Dataset/example reuse.
- Documentation completion and demo conversion.
- GitHub stars as a secondary awareness metric.

## Portfolio rule

Do not claim adoption, traction, community demand, or user outcomes until analytics or attributable feedback exists.
