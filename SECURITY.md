# Security Policy

## Supported Versions

During active initial development, security updates are applied to the latest commit on `main`.

## Reporting a Vulnerability

If you discover a security vulnerability or potential credential leak in AgentEval Studio:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories or contact the project maintainers directly.
3. Include clear steps to reproduce, affected versions, and potential impact.

We will acknowledge receipt within 48 hours and work with you on remediation before public disclosure.
