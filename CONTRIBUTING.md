# Contributing to AgentEval Studio

Thank you for your interest in contributing to AgentEval Studio!

## Current Status: Discovery & Research

The project is currently in the **Competitive Research & Product Discovery phase**. We are establishing rigorous teardowns, defining problem hypotheses, and validating requirements before implementing code.

## How to Contribute Right Now

1. **Competitive Insights & Corrections:** If you spot an inaccuracy in our competitive teardowns (`docs/research/teardowns/`), please open an issue or pull request with a link to official documentation.
2. **Practitioner Feedback:** If you evaluate and deploy tool-calling agents in production, share your evaluation bottlenecks and decision processes via GitHub Discussions or issues.
3. **Evaluation Benchmarks:** Contribute open-source tool-calling benchmark datasets or edge cases.

## Contribution Standards

- Every competitive claim must cite primary sources (vendor documentation, official SDKs, public repos).
- Clearly separate facts from product hypotheses.
- Code contributions will follow standard Python formatting (ruff/black) and require unit tests and type annotations.
